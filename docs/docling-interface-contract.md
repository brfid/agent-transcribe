# Conversion module interfaces

These interfaces define the conversion module boundaries. Use synthetic tests; source files and accepted outputs remain read-only. Mechanical records use kind `docling-folder`, schema 1. Boundaries use JSON-ready dictionaries except for native DoclingDocument objects.

## Selection (B)

`build_folder_plan(root, output, *, recursive=False, sources_file=None, exclude=(), reuse_from=()) -> dict`
Metadata-only: no source payload reads or implicit materialization. Fields: kind, schema, source_root absolute, output absolute, sources ordered list, exclusions list, issues list. Each source has `relative_path`, `order` (1 based), `kind` (pdf,image,tiff,txt,docx or unknown), `size`, `mtime_ns`, `sha256` (known receipt hash or null), `hash_status`, `reuse` (null or record), `prior_coverage` (verified_complete/partial/no_recorded_processing/unresolved). Reuse record identifies accepted text_path, text_sha256, source_sha256, receipt_path/hash, gaps, group/name/notes and provenance. Do not assert verified source history from unmatched metadata or an uninspected original.
`prepare_source(root, entry, *, fetch_inputs=False) -> dict` validates safe exact path, icmat when required, before/after stat+hash, detects allowlisted content format, validates pinned reuse text/hash/provenance. Returns enriched entry with `absolute_path`, `sha256`, `kind`, optional `intake` and reuse; raises IntegrityError for identity conflicts, ordinary OSError/RuntimeError for independent unavailable input. Keep clear publication/storage classification.
`build_archive_plan(root, *, bindings=None, exclusions=()) -> dict`; bindings is list of dicts: name, source_root (relative or absolute), status, destination, reuse_from list, recursive, sources list optional, priority integer, scope_state (ready/defer), prerequisites job-ID list, readiness_requirements human-note list. Metadata-only exact path sets; authoritative read-only receipt import. Plan kind `docling-archive-plan`, schema 1, source_root, jobs list, exclusions, unresolved, inventory. Each job includes id, action (reuse/enrich/convert/defer), scope_state, source_root, output, sources (same entries), collection, status, prior evidence, prerequisites and readiness_requirements. Job-ID dependencies are validated for type, existence, uniqueness and an acyclic graph; human requirements never become executable dependency IDs. An authorized plan revision resolves human requirements and marks only approved jobs ready. Unknown material is visible/deferred until scoped. No path overlap, or nested derivative/output re-ingestion. Fixed lists never silently expand on execution. `validate_archive_plan(plan)` raises on invalid/overlapping jobs. `write_archive_plan(plan,path)` saves JSON + .md readable exact source sets (may use linked source lists if huge). Must preserve accepted capture/reading order when recorded. `load_archive_plan(path)` validates.

## Backend (C)

`BackendOptions` dataclass: artifacts_path: str|None=None, threads:int=4, document_timeout:float=300, images_scale:float=3, rotate_clockwise:int=0. `asdict` must work. Pinned docling 2.142.1, core 2.103.1, parse 7.22.4. See [installation](installation.md#conversion-candidate) for the isolated environment and explicit local model setup. Pinned Pillow 12.3.0 satisfies core <13 (legacy is 13; keep separate). No automatic models during conversion. Preflight exact local artifacts and English/OSD before any inference. Expose `preflight(options)->dict` including versions/model hashes; allow TXT-only operation without models. Explicit CPU/Tesseract CLI, queue 1, no remote services/plugins.
`inspect_source(path, kind) -> dict`: expected_count int|null, unit_kind page/frame/line/package, units list with unit_id (positive integer for page/frame; string okay for package/lines), count_method, count_warnings. PDF/TIFF independently counted, unknown total never complete; preserve known prefix if enumeration fails.
`DoclingBackend(options)` keeps warm converters. `convert_range(path, kind, start, end, *, mode='default', scratch=None) -> dict`; ranges inclusive original numbering, modes default/full_page/pdfium. Result: document native DoclingDocument or None; units list rows `unit_id`, `decode_status` (ok/failed/unknown/not_applicable), `conversion_status` (ok/failed/partial), `text` (all visible body/furniture/notes and picture descendants), `recognition_warnings` list, `error` optional, `doc_page_no` original number for normal conversion, `transform` dict, `attempts` list. Top-level status/errors, start/end, provenance. TXT/DOCX use 1,1 sentinel range and structural/line locators; no invented physical pages. Return native JSON document for successful Docling results. Explicit page errors/failed placeholders override pages existence. Detection warnings never silently replace preferred text.
`render_units(path, kind, unit_ids, destination, *, rotate_clockwise=0, images_scale=3) -> list[dict]`: independent full-page decode/render (not inferred success), rows unit_id, decode_status, asset relative to destination or None, width/height/DPI/transform/errors. All expected image/PDF/TIFF units including blanks. Safe per-frame normalization exactly once then explicit clockwise rotation. Support independent later-frame decode even after middle failure. DOCX/TXT return not_applicable rows. Paths produced only inside destination.

## Portable (D)

`export_part(result, directory, *, source, rendered=()) -> dict`: writes new staged part only, native document.json/Markdown relative referenced assets, page text, crops for each figure/table provenance using base DocItem get_image. source is enriched B entry. Rendered assets are inside directory (F passes directory/assets-rendered to C; rendered rows asset rebased to directory). Returned JSON-safe manifest includes units, files relative to directory with sha256/size, item_refs mapping exact source original unit, native JSON link, errors/warnings. Keep native IDs across parts, no merges. Plain TXT or partial DOCX salvage may have no native document and must identify that fact rather than fake native JSON.
`write_item(bundle_root, item_relative, source, inventory, parts, *, reuse=None) -> dict`: final checked source-map.json, reading.md (accepted text preferred), pages.md candidate for unmapped legacy text, README; links to copied `Originals/<relative_path>` and exported parts. parts each carries `relative_path` relative to item and export manifest. No original copy here (F owns copy). Returns map plus files manifest; all fields explicit; no count complete for unknown total. Expected units must equal accounted disjoint units. Empty text distinct from failure. Notes/provenance labeled separately. Bundle relocation must work.
`write_bundle_views(bundle_root, receipt) -> dict`: root README/readings.txt/issues.md/closeout.md, returns files manifest. receipt includes sources list with item_relative, source, inventory, parts, state, map fields/results. Adapt only with F agreement.
`verify_bundle(root) -> dict`: read conversion.json, mechanical verification including hashes, safe relative paths, all Markdown/JSON links, decode all stored images, source accounting, no symlinks, no external required assets. Return valid, coverage_accounted, conversion_complete, publication_complete, recognition_warnings, errors, exit_code 0/2/1. Pending receipt verifies accepted checkpoints but exit2. Never convert pending to successful.

## Recovery (E)

`recover_range(backend, path, kind, start, end, result, *, scratch, rendered=()) -> dict`: runs only finite eligible stages and returns result with retained variants, attempts, errors, source mapping; never changes accepted outputs. Singleton failed units; alternate PDF backend; qpdf scratch rewrite + count/order checks (warning3 preserved); independent raster rescue; FULL_PAGE candidate for mechanical empty/junk; bounded orientation candidates; later TIFF units survive; partial DOCX ZIP/XML/media salvage; strict TXT/BOM then explicit legacy candidate. Never catch/continue IntegrityError, ENOSPC/EDQUOT or publication failures. Optional capabilities absent => explicit issue, not false completion. Expose attempt caps for deterministic tests. Result may carry `variants` list of additional result dictionaries. No retry explosion.

## Orchestration (F)

`convert_folder(plan, *, options=None, fetch_inputs=False, retry_failed=False) -> dict`; options BackendOptions or dict. Frozen B folder plan, sources may be preselected by consolidated plan. One warm isolated child owns inference/backend; watchdog600 and one crash restart, finite failure semantics. Independent rendering checkpoint saved before inference. Ranges16. Worker may export prepared part via D rather than pickle native document. Persist prepared immutable bytes/hash then guarded accept; accepted bytes unchanged, pending recoverable. Only F writes conversion.json and owns copies, locks, snapshots, spec checks. Per-source unavailable gap okay; integrity/space/publication conflict stops. A recorded-size lower bound is checked before intake/fetch; the detailed remaining-original/page-asset/in-flight-repair estimate is checked before replay/copy and each range, retaining unknown-count/size limits. Refuse changed options/originals/reuse/accepted outputs. Complete exit_code fields. Repeated exact command resumes; new files cannot silently expand selection. Completed failed budgets do not repeat without retry_failed; new retries are additional variants retaining accepted bytes.
`run_archive_plan(plan_or_path, *, options=None, fetch_inputs=False, retry_failed=False) -> dict` validates frozen sources/overlap/destinations, respects scope_state and prerequisites, uses same converter; receipt-derived progress summary only; stop integrity failures, continue content gaps. Permission for execution separate from plan creation (archive plan generated now scope_state=defer with reason approval required; software tests can use ready). `verify` uses D verify_bundle.

Keep CLI, package metadata, installation, dependency lock, documentation and tests consistent with these boundaries. Include pinned Docling integration on synthetic inputs in addition to mocks; distinguish executed checks from deferred checks.
